# Privacy Policy

**Daily Viral India Shorts** is an automated tool that creates and publishes Hindi
YouTube Shorts for the channel owner.

## Data Used

- Google Trends headlines are used to find current topic ideas.
- Gemini is used to draft original scripts when its API key is available.
- YouTube OAuth is used only to upload videos to the authorized channel.
- Pexels and Openverse are used to find licensed stock visuals and music.
- API keys and OAuth tokens are stored as private GitHub Actions secrets.

## Data Storage

The workflow does not maintain a user database or sell personal information.
Temporary audio, image, and video files are deleted at the end of each run.
The channel owner may retain uploaded videos and their public metadata on YouTube.

## Third Parties

The workflow depends on Google, YouTube, GitHub Actions, Gemini, Pexels, Openverse,
and Microsoft Edge TTS. Their own privacy policies and terms also apply.
